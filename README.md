# 小学校理科 用語クイズ

AIエージェントとGitHubを使って作る練習用Webアプリです。

## 現在の機能

- 3〜6年生から学年を選択
- 全学年モード
- 最大10問をランダム出題
- 4択形式
- 正誤と簡単な解説を表示
- 得点と結果を表示
- もう一度挑戦できる

## ファイル

- `index.html`：画面の構造
- `style.css`：見た目
- `script.js`：問題データとクイズの動作

## 今後追加したい機能

- 教科書の単元ごとに問題を選べるようにする
- 問題数を増やす
- 間違えた問題だけ復習する機能
- 教師が問題を追加・編集しやすい仕組み
- GitHub Pagesで公開してiPadから使えるようにする
